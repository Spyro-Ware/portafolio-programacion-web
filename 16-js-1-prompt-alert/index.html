JS 1 - Prompt y Alert

En esta actividad se usa prompt para pedir un dato al usuario y alert para mostrar un mensaje en pantalla.

Ejemplo 1: Saludo con tu nombre

Pulsa el botón, escribe tu nombre y verás un saludo.

Ejemplo 2: Tu color favorito

Pulsa el botón, escribe tu color favorito y verás un mensaje con tu respuesta.
