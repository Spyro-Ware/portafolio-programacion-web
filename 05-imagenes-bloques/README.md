# Bloques de un diagrama de flujo

Cada archivo SVG de esta carpeta es un bloque del diagrama de flujo del pedido en la cooperativa de la Preparatoria 9.

- bloque-inicio.svg: óvalo, marca el inicio del diagrama.
- bloque-proceso.svg: rectángulo, es un paso o una acción del proceso.
- bloque-decision.svg: rombo, es una pregunta con dos caminos, sí o no.
- bloque-entrada-salida.svg: paralelogramo, es una entrada o salida de datos, como ver el menú o mostrar el pedido.
- bloque-fin.svg: óvalo, marca el fin del diagrama.
- diagrama-completo.svg: diagrama pequeño completo del pedido en la cooperativa, de inicio a fin.
