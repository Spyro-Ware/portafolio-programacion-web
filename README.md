# Portafolio de Programación web

Autor: Leonardo Santiago Briones Tafolla
Escuela: Preparatoria 9
Grupo: 3-H
Materia: Programación web
Entrega: sábado 21 de noviembre de 2026

## Contenido

1. `01-algoritmo-prefectura` - Algoritmo para llegar a prefectura desde la entrada principal.
2. `02-algoritmo-problema-social` - Algoritmo del problema de las filas en la cooperativa.
3. `03-diagrama-flujo-problema-social` - Diagrama de flujo del problema de la cooperativa.
4. `04-pseudocodigo-problema-social` - Pseudocódigo del problema de la cooperativa.
5. `05-imagenes-bloques` - Imágenes en SVG de los bloques del diagrama de flujo.
6. `06-act-int-1-problema-local` - Act Int 1: algoritmo, diagrama y pseudocódigo de un problema local.
7. `07-html-1-texto-titulos` - HTML 1: texto y títulos.
8. `08-html-2-receta` - HTML 2: receta con ingredientes y pasos.
9. `09-html-3-formulario` - HTML 3: formulario.
10. `10-html-4-horario-v1` - HTML 4: horario en tabla simple.
11. `11-html-5-horario-v2` - HTML 5: horario en tabla con CSS.
12. `12-css-1-colores` - CSS 1: colores de texto y fondo.
13. `13-css-2-bordes-margen` - CSS 2: bordes y margen.
14. `14-css-3-fuentes-hover` - CSS 3: fuentes y hover.
15. `15-act-int-2-sitio-tematico` - Act Int 2: sitio web temático de la Preparatoria 9.
16. `16-js-1-prompt-alert` - JS 1: prompt y alert.
17. `17-js-2-if-condiciones` - JS 2: if y condiciones.
18. `18-js-3-nacionalidad-edad` - JS 3: nacionalidad y edad con prompt e if.
19. `19-act-int-3-js-sitio-web` - Act Int 3: sitio web temático con JavaScript, modo oscuro, formulario validado y menú que se muestra y oculta.
