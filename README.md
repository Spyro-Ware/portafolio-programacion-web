# Portafolio de Programación web

Autor: Leonardo Santiago Briones Tafolla


## Contenido

1. `01-algoritmo-prefectura` - Algoritmo para llegar a prefectura (fotos de libreta).
2. `02-algoritmo-problema-social` - Algoritmo del problema social: comprar mayonesa para el sándwich (fotos de libreta).
3. `03-diagrama-flujo` - Diagrama de flujo del sándwich (foto de libreta).
4. `04-pseudocodigo` - Pseudocódigo del sándwich (foto de libreta).
5. `05-imagenes-bloques` - Imágenes de los bloques de Blockly (operadores, if/else con edad, ciclos y suma de números).
6. `06-act-int-1-problema-local` - Act Int 1: calcular la calificación final (actividades 30%, examen 40%, proyecto 30%) y determinar si aprobó.
7. `07-html-1-texto-titulos` - HTML 1: texto y títulos (Hola mundo, listas y definiciones).
8. `08-html-2-receta` - HTML 2: receta de enchiladas suizas con ingredientes y pasos.
9. `09-html-3-formulario` - HTML 3: cuestionario sobre gustos personales.
10. `10-html-4-horario-v1` - HTML 4: horario en tabla simple.
11. `11-html-5-horario-v2` - HTML 5: horario en tabla con CSS.
12. `12-css-1-colores` - CSS 1: colores de texto y fondo (del sitio Tecnología y Gadgets).
13. `13-css-2-bordes-margen` - CSS 2: bordes y margen (del sitio Tecnología y Gadgets).
14. `14-css-3-fuentes-hover` - CSS 3: fuentes (Space Grotesk y Rajdhani) y hover en tarjetas.
15. `15-act-int-2-sitio-tematico` - Act Int 2: sitio web temático de Tecnología y Gadgets.
16. `16-js-1-prompt-alert` - JS 1: prompt y alert (suma de dos números).
17. `17-js-2-if-condiciones` - JS 2: if y condiciones (edad: mayor, adolescente o niño).
18. `18-js-3-nacionalidad-edad` - JS 3: nacionalidad y edad con prompt e if (main.js).
19. `19-act-int-3-js-sitio-web` - Act Int 3: sitio web temático de Tecnología y Gadgets con JavaScript (botón de modo claro).
